## Лабораторная работа №2

Многостраничный web-сайт **Avatar Lab** на тему видеоуправляемых цифровых аватаров.

### Структура сайта

- [Главная страница](lab2/index.html)
- [Описание технологии](lab2/technology.html)
- [Этапы создания аватара](lab2/process.html)

Сайт разработан на HTML и CSS без JavaScript, библиотек и фреймворков. В проекте используются блочные и строчные элементы, локальное изображение, ссылки, таблица, различные виды селекторов, цвета и простая адаптивная вёрстка.

Для просмотра откройте файл `lab2/index.html` в браузере.
